# Политика разрешений

Начальный профиль предназначен для чтения веб-источников, поиска, memory, Telegram-уведомлений и ограниченных subagents.

Разрешены группы `group:web`, `group:memory`, `group:messaging`, а также запуск изолированных subagents. Запрещены `group:runtime`, `group:fs`, управление Gateway, создание cron-задач самим агентом и межсессионная отправка через `sessions_send`.

Практические следствия:

- агент не получает shell и не может выполнять SSH или deployment;
- агент не может изменять файлы даже внутри workspace;
- расписания создаёт оператор через CLI, а не входящее сообщение;
- Telegram pairing ограничивает круг отправителей, но не заменяет tool policy;
- финансовые транзакции, покупки и торговля не должны подключаться к этому профилю.

Расширяйте разрешения только для конкретного агента и конкретной задачи. После каждого изменения запускайте `openclaw security audit --deep` и проверяйте эффективный список инструментов через штатные диагностические команды.
