# Политика разрешений

Начальный профиль предназначен для чтения веб-источников, поиска, ведения memory и профильных файлов в workspace, Telegram-уведомлений и ограниченных subagents.

Разрешены группы `group:web`, `group:memory`, `group:messaging`, `group:fs`, а также запуск изолированных subagents. `tools.fs.workspaceOnly: true` ограничивает файловые операции каталогом агента. Запрещены `group:runtime`, управление Gateway, создание cron-задач самим агентом и межсессионная отправка через `sessions_send`.

Практические следствия:

- агент не получает shell и не может выполнять SSH или deployment;
- агент может читать и изменять `IDENTITY.md`, `USER.md`, `SOUL.md`, `MEMORY.md`, `memory/*.md` и другие материалы только внутри workspace;
- агент не может читать `.env`, restic secrets, runtime config или произвольные host-файлы за пределами workspace;
- расписания создаёт оператор через CLI, а не входящее сообщение;
- Telegram pairing ограничивает круг отправителей, но не заменяет tool policy;
- финансовые транзакции, покупки и торговля не должны подключаться к этому профилю.

Расширяйте разрешения только для конкретного агента и конкретной задачи. После каждого изменения запускайте `openclaw security audit --deep` и проверяйте эффективный список инструментов через штатные диагностические команды.
